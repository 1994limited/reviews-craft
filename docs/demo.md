# The demo

Dog-ear Books is a made-up bookshop for trying Reviews: ten books as Commerce products, two journal entries, and sixty reviews, some waiting for an editor, with replies, criteria, helpful votes and a customer's verified review.

It's at [github.com/1994limited/reviews-craft-demo](https://github.com/1994limited/reviews-craft-demo). See its README for running it with DDEV or Herd.
